# MOMS Design

**Marketing Operations Management System** is a subscription marketing service that turns a business's goals and public web presence into prioritized work, authorized execution, and measured results.

Start with [REPO_START_HERE](REPO_START_HERE.md). The [master design index](docs/design/master-design-index.md) identifies the owner document for each concept.

## First delivery

Public domain + ordinary-language business objectives + target geography → research and website assessment → prioritized Marketing Work List → readable customer report → persisted baseline.

This repository contains product design and engineering instructions, not a working application. Google Ads read/recommend is the next capability; Ads writes require a later work package and explicit controls.

## Authority

The five supplied handoffs are reconciled here as the initial design baseline. Their original bytes are retained in [source handoffs](docs/reference/handoffs/README.md). Source-backed requirements are distinguished from proposed implementation details and unresolved decisions. No price, technology stack, vendor contract, or production release approval is implied.
