# Repository Access and Bootstrap History

Canonical repository: [jeretrax/moms-design](https://github.com/jeretrax/moms-design).

## Work from the canonical repository

```bash
git clone https://github.com/jeretrax/moms-design.git
cd moms-design
```

Read [REPO_START_HERE](REPO_START_HERE.md), [governance](docs/design/design-to-implementation-governance.md), and [design notes](docs/design/design-notes.md) before changing the design. Fetch and reconcile remote changes before publication. Do not force-push over existing work.
